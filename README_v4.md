## 사용법 요약
- **대표성분 구성 (복합 성분)**: 선택 입력 > 대표성분 함량 아래.
  `8종 마이크로바이옴 (8 Microbiome Complex) = 비피다발효여과물, 락토바실러스발효용해물, … | 무너진 피부 밸런스 유지 / 약해진 피부 환경을 건강하게 가꾸는 마이크로바이옴 콤플렉스`
  - `| 수식어 / 설명`은 생략하면 브랜드 톤 기본 문장이 들어갑니다.
  - 전성분만 넣어도 마이크로바이옴 · 아쿠아포린 · COOLIF™ · 펩타이드 · 프로바이오틱스 · 식물성 뮤신 · 세라마이드 · 다중 히알루론산 · 과일추출물을 자동 감지합니다 → [감지한 복합 성분을 입력칸에 채우기].
  - Word 템플릿에 「대표성분 구성」 행을 추가하면 업로드할 때 자동으로 채워집니다.
- **＋ 텍스트 상자**: 편집 화면 상단 [저장] 왼쪽. 누른 뒤 원하는 위치를 클릭 → 파란 점선 상자 생성.
  상자에 마우스를 올리면 [이동 · B · A− · A＋ · 정렬 · ×] 메뉴. 오른쪽 아래 모서리를 끌면 폭 조절.
  히스토리별로 저장되고 엑셀 다운로드에도 들어갑니다. (히스토리 백업 JSON에는 포함되지 않습니다)
- **피부 자극 테스트 결과**: 보고서 결론 문장을 그대로 넣거나, 평균 피부 반응도 숫자(0.00)만 넣으면 기존 문장 형식으로 완성됩니다.
  자료가 없으면 [0.00] · [시험기관] 자리표시가 주황 박스로 남습니다. 결과 수치는 자동으로 만들지 않습니다.
