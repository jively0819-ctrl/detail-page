# v6 변경 사항 (벨리닉 보완 · 시트 마스크 판별)

## 올리는 파일
- index.html (교체) — js/v6-fix.js 연결 1줄 추가
- js/v6-fix.js (신규)
- layouts/velinic/img/v6_05.jpg (신규) — 텍스처 영역 원본 문구 삭제 이미지

## 내용
1. 벨리닉 인트로 성분 버블 2·3 문안 생성 (대표성분이 부족하면 복합/서포트 성분으로 채움, 없으면 입력 안내 박스)
2. 벨리닉 텍스처 영역: 배경 문구 삭제 이미지로 교체, 헤드라인·단계 박스 확장, 제형 사진 교체 안내 박스
3. 제품 유형: 이름에 '마스크'만 있어도 설명/용량에 시트·매 등이 있으면 시트 마스크로 판별
   [선택 입력 > 제품 유형]에서 직접 지정 가능
기존 히스토리는 [다시 생성]을 눌러야 반영됩니다.
