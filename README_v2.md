## v2 변경 사항 (문구 전체 배치 · 기존 문안 톤 적용)

- **문구 자리 전체 생성**: 닥터에스떼 57칸, 벨리닉 67칸. 기존 디자인요청서 엑셀에 있던 문구 자리마다 박스가 하나씩 생깁니다. 이전 버전은 약 20칸만 있어서 문구가 띄엄띄엄 나왔습니다.
- **기존 문안 톤 사전(js/tone.js)**: 「엑토인 1% 레스큐 토너」, 「고마쥬 멜팅 봄므」 요청서 문장을 패턴으로 옮겼습니다.
  - 닥터에스떼: `OO 1%, OO 2.7% 함유로 / 피부를 속부터 탄탄하게!`, `~하신 분`, `OO를 만나보세요.`
  - 벨리닉: `셀룰로오스 필링 비즈 함유로 / 매끈하게 결을 다듬는 스크럽감`, `~찾으시는 분`, 악장(1st/2nd/3rd Mov.) 구성
- **전성분만으로 작성**: 대표성분을 비워 두면 전성분에서 자동으로 고릅니다. `8종 마이크로바이옴`, `5종 과일추출물` 같은 묶음 표기도 자동으로 만듭니다.
- **함량 표기**: 제품명이나 [대표성분 함량] 칸에 적은 함량(예: `엑토인 1%, 판테놀 2.7%`)이 성분명 옆에 자동으로 붙습니다.
- **배경 이미지 교체**
  - 닥터에스떼: 엑토인 토너 요청서 이미지 10장(작은 이미지 합성)으로 교체했습니다.
  - 벨리닉: 완성 상세 10장과 상품정보 표 1장을 넣었습니다. 연한 베이지 톤이어서 불투명도 30%에서도 보이도록 대비를 높였습니다.
- **주황 박스**: 시험 자료처럼 추가 입력이 필요한 자리입니다. 자료가 없으면 ×로 지우세요.

### 문장 고치는 법
- 문장 톤 → `js/tone.js` (CAT = 피부 고민별 문장, T = 성분별 문장, KIND = 제품유형별 문장)
- 벨리닉 브랜드 공통 문구(브랜드 스토리 · 벨리닉 사이언스) → `js/config.js`의 `brands.velinic.story`
- 박스 위치 → 사이트에서 [위치 조정] → [현재 위치를 레이아웃 파일로 내보내기] → `layouts/<브랜드>/layout.js` 교체
