## v3 변경 사항 (제품 설명 칸 · 문구 자리 전체 고정 배치)

### 1. [필수 입력] 제품 설명 칸 추가
- 제품명 아래에 **제품 설명** 칸이 생겼습니다. 제품 포인트 · 제형 · 피부 고민 · 강조 성분을 2~5줄로 적으면 됩니다.
- 설명과 전성분을 함께 분석해서 상세 전체 문안에 반영합니다.
  - 피부 고민(보습 · 진정 · 피부결 · 생기 · 밸런스 · 영양 · 산뜻 · 세정 · 쿨링) → 한 줄 카피, 특징, 추천 대상, POINT 문구의 방향
  - 강조 성분(전성분에 있는 성분만) → 대표성분 자동 선택 순서
  - 함량(예: 엑토인 1%) → 성분명 옆 함량 표기
  - 제형(밀키 · 젤 · 워터리 · 에센스 · 리치 · 멜팅 · 거품) → 텍스처 문구
  - 고함량 · 저자극 표현 → "고함량 OO로 완성하는", "저자극 고마쥬 케어"
- 입력 칸 아래에 "설명에서 인식한 포인트"가 바로 표시됩니다.
- Word 입력템플릿에 '제품설명' 행을 추가하면 업로드할 때 자동으로 채워집니다(선택).

### 2. 문구가 뭉치거나 빠지는 문제 수정
- 이전: 박스 높이가 글자 양에 따라 늘어나 아래 박스를 밀어내면서 한곳에 뭉치고, 원래 자리가 비었습니다.
- 지금: 박스 크기를 **디자인요청서 엑셀의 텍스트박스 크기 그대로 고정**하고, 글자 크기를 박스에 맞게 자동으로 줄입니다(js/fit.js).
  - 닥터에스떼 57칸: 「엑토인 1% 레스큐 토너」 엑셀 텍스트박스 좌표 · 크기 · 글자 크기 그대로
  - 벨리닉 67칸: 「고마쥬 멜팅 봄므」 완성 상세의 문구 영역 크기
- 글자가 너무 많아 박스를 넘치면 주황 점선과 "문구를 줄여 주세요" 표시가 나옵니다.
- 엑셀 다운로드에도 화면에서 맞춘 글자 크기가 반영됩니다.
