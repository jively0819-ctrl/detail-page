## 바뀐 점
1. 상품정보제공고시: v4의 목록형 박스 하나(infoAll)를 없애고 v2 방식으로 되돌렸습니다.
   - 닥터에스떼: 제품명 · 용량 · 사용방법 · 전성분 4칸
   - 벨리닉: 제품명 · 용량 · 기능성 · 사용방법 · 전성분 5칸
   - 칸 위치와 문구 형식은 v2 그대로이고, 박스 높이만 v3 엑셀 박스 높이를 씁니다.
2. 닥터에스떼 복합성분 상세 영역(What is …?)
   - 배경: 사진 위 콜라겐 원형 그림과 표 안의 다른 제품 문구를 지웠습니다. 표 선은 그대로 남겼습니다.
   - 사진 가운데: 성분명 라벨 (예: 8종 마이크로바이옴 / 8 Microbiome Complex)
   - 표 1행: 복합 성분 구성 (왼쪽 영문 타이틀, 오른쪽 구성 성분 · 조합 설명 · 굵은 설명 줄)
   - 표 2행: 다음 대표성분(예: 엑토인 1%)의 설명. 복합 성분이 없으면 대표성분 1 · 2로 채웁니다.
   - 문구 수정 위치: js/v5-fix.js 의 tableLines()
3. [새 텍스트] 아이콘: 편집 화면 상세페이지 오른쪽 위에 있고, 스크롤해도 따라옵니다.
   누른 뒤 원하는 위치를 클릭하면 파란 점선 텍스트 상자가 생깁니다. (기존 [＋ 텍스트 상자] 기능과 같고, 엑셀에도 들어갑니다)
